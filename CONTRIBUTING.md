# Contributing

Thank you for helping keep this collection useful.

## Before submitting

- Search the README to avoid duplicates.
- Link only to the project’s official repository.
- Prefer mature, actively maintained projects with clear documentation and licensing.
- Write a short, factual description—one sentence is ideal.
- Do not submit commercial products, forks without a distinct purpose, or link-only collections.

## Pull request format

Add one row to the appropriate table:

```md
| [Project](https://github.com/owner/project) | What it does and why it stands out. |
```

Keep entries alphabetical within each section whenever practical. By contributing, you agree that your contribution may be distributed under the repository’s MIT License.
