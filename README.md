## Why this list

Open source is much larger than a star count. This collection favors projects that are actively maintained, broadly useful, well documented, and trusted in real-world work. Entries are intentionally selective: every link should be worth your click.

## How to use this collection

1. Pick a category that matches the problem you are solving.
2. Open the project’s official repository and read its license, documentation, and security guidance.
3. Try it in a small, non-production environment first.
4. If it earns a place in your stack, star it, contribute, or sponsor the maintainers.

## Submit a project

Know something extraordinary that belongs here? Open an issue or pull request. Please include:

- The official repository link
- A one-sentence explanation of its value
- Why it is actively maintained and broadly useful
- The category where it belongs
